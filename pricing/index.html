Pricing, eligibility and plan scope

Review Pricing, eligibility and plan scope: Public pricing explains the subscription choices without requiring a preliminary sales conversation.

Full Markdown
Home / pricing

Overview

A webinar plan should be evaluated against the required delivery format, simultaneous attendees, integrations, usage and exit terms. The cheapest live plan is not automatically the cheapest plan that supports automation.

This review draft uses the supplied 16 September 2026 plan matrix as a dated reference. It does not provide a current purchase quotation or imply that those prices and limits remain unchanged. Resolve the production pricing and structured-data contradictions before release.

Plan matrix — source dated 16 September 2026

Launch: monthly reference $44; annual-equivalent monthly reference $36; live / automated allocation 50 / 0. Source notes: Live only; AI builder 2 funnels/month; presenter-count wording needs confirmation.

Growth: monthly reference $116; annual-equivalent monthly reference $96; live / automated allocation 200 / 1,000. Source notes: Automation, simulive/evergreen, EasyCRM, checkout, EasyCast; listed CRM/email integrations.

Pro: monthly reference $198; annual-equivalent monthly reference $165; live / automated allocation 500 / 2,500. Source notes: Lead scoring; API scope requires confirmation.

Scale: monthly reference $349; annual-equivalent monthly reference $291; live / automated allocation 1,000 / 5,000. Source notes: Routing; full API; webhooks; SSO/SAML; white-label scope requires confirmation.

Enterprise: monthly reference Contact sales; annual-equivalent monthly reference Contact sales; live / automated allocation Disputed maximum. Source notes: Custom quotation; do not publish a confirmed 100,000-attendee guarantee.

How to compare total cost

Count the lowest eligible plan, external CRM and email subscriptions you retain, processor charges, SMS or sending usage, any overages and implementation effort. A tool already owned is not automatically a saving just because a similar module exists in the webinar platform.

For an automated funnel, use the lowest plan that actually enables automation. For a one-off live session, compare the event’s genuine requirements before choosing a broader stack. Current purchase terms and cancellation rights need validation.
