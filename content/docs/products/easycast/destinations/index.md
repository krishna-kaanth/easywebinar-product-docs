# Products Easycast Destinations

A streaming destination is the external platform or endpoint receiving the broadcast. Named destination support and simultaneous destination count are different facts; neither establishes the audience permissions of the external service.

Test each intended account and destination before promoting the event. An external viewer’s interaction and offer path differ from the native webinar room.
