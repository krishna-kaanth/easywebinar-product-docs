# EasyCast multistreaming

EasyCast extends a webinar broadcast to supported external streaming destinations such as YouTube Live, LinkedIn Live, Facebook Live and compatible custom RTMP destinations.

External distribution can broaden reach, but the external audience does not automatically have the native room’s registration identity, chat controls or transaction attribution. Inspect the offer-link or QR workflow, destination permissions and simultaneous-stream limits.

## U172 · Number of simultaneous destinations

Status: Partial / plan-gated

Simultaneous-destination limits define how many external streams can be active together.

### What is this feature or requirement for?

Simultaneous-destination limits define how many external streams can be active together.

### How does it help?

The producer can plan which channels fit the supported broadcast configuration.

### What happens if you do not have it?

A campaign may promise distribution to more destinations than the account or delivery setup permits.

### Why should it matter to the buyer?

It matters for reach planning; the number of destination types is not the same as the count of concurrent destinations.

### Workflow evaluation

Choose a real event timezone and two distinct test attendees. Compare the registration choices, confirmation details, session start, recording playback and permitted interaction. Repeat the test for the exact delivery format you intend to use.

The registration schedule, room behaviour and replay policy are related but not interchangeable. Check supported formats and plan eligibility before assuming a setting applies to live, simulive and on-demand delivery alike.
