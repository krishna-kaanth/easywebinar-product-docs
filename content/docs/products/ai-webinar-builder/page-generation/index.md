### What is this feature or requirement for?

AI-generated pages create draft webinar page content through a guided generation workflow.

### How does it help?

The team can start with coordinated registration, thank-you and waiting-room content rather than a blank page.

### What happens if you do not have it?

Copy and page content must be authored manually or prepared in a separate tool.

### Why should it matter to the buyer?

It matters for faster first drafts; generated copy still needs factual review, brand editing and a real event configuration.

### Workflow evaluation

Build a sample registration journey using the intended brand and campaign. Submit a test signup on desktop and mobile, inspect the success step and compare the saved record with the information you expected to collect.

A polished form is only one part of registration. Domain setup, consent, source retention, field mapping and the actual attendee access path each need separate validation.

## U158 · AI page and copy generation

Status: Supported in source

AI page and copy generation creates draft messaging for supported webinar pages.

### What is this feature or requirement for?

AI page and copy generation creates draft messaging for supported webinar pages.

### How does it help?

The team can align registration and related page content around the same event and offer.

### What happens if you do not have it?

Each page needs separate drafting and consistency checks from a blank starting point.

### Why should it matter to the buyer?

It matters for reducing first-draft effort; generation does not publish a fact-checked campaign or guarantee improved conversion.

### Workflow evaluation

Choose a real event timezone and two distinct test attendees. Compare the registration choices, confirmation details, session start, recording playback and permitted interaction. Repeat the test for the exact delivery format you intend to use.

The registration schedule, room behaviour and replay policy are related but not interchangeable. Check supported formats and plan eligibility before assuming a setting applies to live, simulive and on-demand delivery alike.
