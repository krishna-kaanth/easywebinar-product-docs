# Products and platform modules

EasyWebinar combines webinar delivery with supporting registration, engagement, conversion and follow-up workflows. The module names describe different parts of that system: live hosting, automated delivery, on-demand access, the guided AI builder, EasyCRM and EasyCast.

Start with the delivery format needed for the job, then inspect shared feature pages for details. A module being available does not mean every small requirement on this site is supported or that all capabilities are included in the entry plan.
