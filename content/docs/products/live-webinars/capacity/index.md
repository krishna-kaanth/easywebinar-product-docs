# Capacity — maximum live attendees

Live capacity describes the supported audience size under a particular plan and delivery configuration.

This page explains the requirement in the context of EasyWebinar and preserves the supplied inventory status. Read the evidence section before treating an explanation of buyer value as a promise of current product support.

## U47 · Capacity — maximum live attendees

Status: Partial / plan-gated

Live capacity describes the supported audience size under a particular plan and delivery configuration.

### What is this feature or requirement for?

Live capacity describes the supported audience size under a particular plan and delivery configuration.

### How does it help?

The organiser can choose a plan and operational setup suitable for the expected simultaneous audience.

### What happens if you do not have it?

An event may encounter limits at the moment traffic arrives, requiring an overflow path or another product.

### Why should it matter to the buyer?

It matters for high-stakes launches; registrations, concurrent room attendees and external stream viewers must not be combined into one unexplained capacity number.

### Workflow evaluation

Rehearse with the intended cameras, microphones, slides and speaker arrangement. Ask test attendees to inspect the relevant behaviour from the audience side, and check the recording as well as the live presentation.

A successful small rehearsal does not establish large-audience performance. Exact concurrency, latency, session-duration and recovery claims need scoped product documentation or an agreed test.
