## EW23 · Expired-session redirect

Status: Supported in source

An expired-session redirect sends a visitor to a custom page when the original session is no longer available.

### What is this feature or requirement for?

An expired-session redirect sends a visitor to a custom page when the original session is no longer available.

### How does it help?

A late visitor can receive a useful explanation and a current alternative instead of a dead end.

### What happens if you do not have it?

The visitor encounters the default expiry experience and may not know the next available action.

### Why should it matter to the buyer?

This is different from a normal end-of-webinar redirect and from replay expiry. The destination should explain availability honestly rather than imply a closed session is still live.
