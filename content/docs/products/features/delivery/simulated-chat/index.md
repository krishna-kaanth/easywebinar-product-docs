## U20 · Simulated live chat in automated sessions

Status: Supported in source

Simulated chat replays configured chat activity alongside a recorded webinar session.

### What is this feature or requirement for?

Simulated chat replays configured chat activity alongside a recorded webinar session.

### How does it help?

It can add context to the recorded presentation and show questions that were discussed during its original delivery.

### What happens if you do not have it?

A replay may lack the accompanying conversation, leaving references to chat or audience reactions unclear.

### Why should it matter to the buyer?

It matters when contextual chat is useful; replayed or simulated messages should not imply that those viewers are currently present.

### Workflow evaluation

Choose a real event timezone and two distinct test attendees. Compare the registration choices, confirmation details, session start, recording playback and permitted interaction. Repeat the test for the exact delivery format you intend to use.

The registration schedule, room behaviour and replay policy are related but not interchangeable. Check supported formats and plan eligibility before assuming a setting applies to live, simulive and on-demand delivery alike.

## EW20 · Live chat export for simulated chat

Status: Supported in source

The documented export prepares live chat in a format intended for simulated chat in an evergreen webinar.

### What is this feature or requirement for?

The documented export prepares live chat in a format intended for simulated chat in an evergreen webinar.

### How does it help?

The organiser can evaluate reuse of relevant audience questions around the recorded presentation.

### What happens if you do not have it?

Chat needs another supported preparation method or the recorded event omits that contextual conversation.

### Why should it matter to the buyer?

Preserve the distinction between a replayed conversation and a current live attendee. Review personal information, attribution, timing and outdated offer references before reuse.

### Workflow evaluation

Run a short test presentation with a host and an attendee. Trigger the relevant interaction, inspect what both sides see and check any resulting data or follow-up. For recorded sessions, repeat at the relevant playback timestamp.

An interaction visible in the live room may have different controls or limits in automated playback and external streams. Verify the format rather than treating every engagement tool as universally available.
