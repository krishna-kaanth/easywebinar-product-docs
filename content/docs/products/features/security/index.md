# Access and identity controls

Access controls govern account sign-in or attendee admission. Verify the actual protected surface and identity flow rather than inferring private event access from host-account SSO.

The child pages explain each requirement with its purpose, practical benefit, absence cost, importance and source status. Partial or unconfirmed entries remain visibly labelled for team validation.
