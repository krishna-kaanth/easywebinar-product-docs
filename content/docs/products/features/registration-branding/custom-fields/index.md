## U82 · Custom registration fields

Status: Partial / plan-gated

Custom registration fields collect information beyond the standard signup details.

### What is this feature or requirement for?

Custom registration fields collect information beyond the standard signup details.

### How does it help?

The team can ask for relevant qualification or audience context before the webinar.

### What happens if you do not have it?

Records may lack the information needed to segment follow-up or evaluate whether registrants fit the intended audience.

### Why should it matter to the buyer?

It matters for B2B qualification; extra fields also increase effort and require an appropriate purpose and handling policy.

### Workflow evaluation

Build a sample registration journey using the intended brand and campaign. Submit a test signup on desktop and mobile, inspect the success step and compare the saved record with the information you expected to collect.

A polished form is only one part of registration. Domain setup, consent, source retention, field mapping and the actual attendee access path each need separate validation.

Status: Supported in source

### What is this feature or requirement for?

Custom fields can appear in the documented registration-page and embed-widget workflow.

### How does it help?

A campaign can gather relevant qualifying information even when registration is presented on an external page.
