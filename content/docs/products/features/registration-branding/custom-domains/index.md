# Custom domain (CNAME)

A custom domain serves supported webinar pages through a domain associated with the customer's brand.

This page explains the requirement in the context of EasyWebinar and preserves the supplied inventory status. Read the evidence section before treating an explanation of buyer value as a promise of current product support.

## Product and workflow context

Custom domain (CNAME) sits in the registration branding layer of the webinar workflow. Evaluate it together with the event format, the account’s eligible plan and any external provider involved. Its detailed parameter explanation below covers both the benefit and the limits of relying on it.

The supplied source is an inventory rather than a current implementation manual. Exact configuration steps, UI screenshots and supported limits must be attached during review; this draft does not invent button labels or silently substitute a different feature.

### What is this feature or requirement for?

A custom domain serves supported webinar pages through a domain associated with the customer's brand.

### How does it help?

The visitor can recognise the brand in the page address as well as the visual design.

### What happens if you do not have it?

The experience uses the provider's domain or requires an external page workflow to maintain a branded address.

### Why should it matter to the buyer?

It matters for brand consistency; clarify supported page types, DNS setup, TLS provisioning and plan eligibility.

## EW37 · Cloudflare CNAME setup

Status: Supported in source

A CNAME record at Cloudflare points the documented custom hostname toward the webinar service's required target.

### What is this feature or requirement for?

A CNAME record at Cloudflare points the documented custom hostname toward the webinar service's required target.

### How does it help?

A campaign can use an approved branded hostname instead of relying only on the default service address.

### What happens if you do not have it?

The organiser uses the supplied platform URL or another verified domain arrangement.
