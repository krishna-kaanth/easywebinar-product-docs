## U81 · Registration embeds on any site

Status: Supported in source

Registration embeds place a signup form on an existing website page.

### What is this feature or requirement for?

Registration embeds place a signup form on an existing website page.

### How does it help?

A visitor can register within the website context where they learned about the event.

### What happens if you do not have it?

They must navigate to a separate registration page or the team must build a form and connection independently.

### Why should it matter to the buyer?

It matters for existing marketing sites; a registration embed collects signups and is not evidence of an embedded webinar player.

### Workflow evaluation

Build a sample registration journey using the intended brand and campaign. Submit a test signup on desktop and mobile, inspect the success step and compare the saved record with the information you expected to collect.

A polished form is only one part of registration. Domain setup, consent, source retention, field mapping and the actual attendee access path each need separate validation.

## EW36 · Embed-widget appearance

Status: Supported in source

Widget customisation adjusts the supported embedded registration experience on another website.

### What is this feature or requirement for?

Widget customisation adjusts the supported embedded registration experience on another website.

### How does it help?

The organiser can integrate signup with an existing campaign page while keeping the webinar registration workflow.

### What happens if you do not have it?

Visitors use the hosted registration page or another supported embed configuration.

### Why should it matter to the buyer?
