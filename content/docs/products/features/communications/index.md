# Communications and follow-up

Communication keeps the attendee connected before and after the presentation. Distinguish draft copy from configured delivery, and use actual attendance and action data when choosing a supported follow-up route.

The child pages explain each requirement with its purpose, practical benefit, absence cost, importance and source status. Partial or unconfirmed entries remain visibly labelled for team validation.
