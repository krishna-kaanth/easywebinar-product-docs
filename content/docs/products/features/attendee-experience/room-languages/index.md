# Multi-language live rooms

Room languages concern the interface text used by attendees, rather than translation of the speaker's content.

This page explains the requirement in the context of EasyWebinar and preserves the supplied inventory status. Read the evidence section before treating an explanation of buyer value as a promise of current product support.

## Product and workflow context

Multi-language live rooms sits in the attendee experience layer of the webinar workflow. Evaluate it together with the event format, the account’s eligible plan and any external provider involved. Its detailed parameter explanation below covers both the benefit and the limits of relying on it.

## EW08 · Attendee session language switching

Status: Supported in source

A participant can manually change the language for their own live-room session.

### What is this feature or requirement for?

A participant can manually change the language for their own live-room session.

### How does it help?

A multilingual audience can choose an individual interface without forcing the same change on everyone else.

### What happens if you do not have it?

Participants remain with the event's configured default and depend on that being appropriate.

### Why should it matter to the buyer?

Personal choice matters when attendees use different languages. A current-user switch must not be presented as a host changing the entire room globally.
