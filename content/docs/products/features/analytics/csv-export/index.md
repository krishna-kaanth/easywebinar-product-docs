## U131 · CSV export

Status: Supported in source

CSV export downloads supported webinar data in a portable tabular format.

### What is this feature or requirement for?

CSV export downloads supported webinar data in a portable tabular format.

### How does it help?

Teams can inspect records, reconcile them with other systems and retain an analysis copy.

### What happens if you do not have it?

The information remains dependent on the interface or another verified integration for access.

### Why should it matter to the buyer?

It matters for analysis and portability; confirm columns, record scope, date format and whether recordings or messages require separate exports.

### Workflow evaluation

Use known test contacts with deliberately different attendance and interaction histories. Compare the displayed metric and any export with those actions. Document the metric’s definition, timeframe and whether live and replay data are separate.

Measured webinar activity is not proof of buyer intent, product adoption or CRM closed-won revenue. Attribution claims need the actual transaction connection and a stated model.

## R3 · Data export / portability

Status: Partial / plan-gated

Data portability concerns the ability to retrieve relevant records and assets when analysing data or leaving the platform.

### What is this feature or requirement for?

Data portability concerns the ability to retrieve relevant records and assets when analysing data or leaving the platform.

### How does it help?

A team can reduce dependence on a single interface and plan an orderly exit.

### What happens if you do not have it?

It may lose useful context or need manual reconstruction when changing tools.

### Why should it matter to the buyer?

It matters for vendor risk; a CSV export does not establish portability of every recording, page, message and automation setting.

### Workflow evaluation

Review an actual exit or escalation scenario. Confirm which records can be exported, what service commitment exists and which operations are documented rather than inferred from reputation.

A long operating history or lack of criticism in an AI diagnostic does not establish an uptime guarantee, financial stability or complete data portability.
