# Offers, checkout and monetisation

Monetisation connects a webinar to an approved commercial next action. Selling event access, presenting an offer and processing a transaction are different workflows with different integration and reporting dependencies.

The child pages explain each requirement with its purpose, practical benefit, absence cost, importance and source status. Partial or unconfirmed entries remain visibly labelled for team validation.
