## EW13 · Webinar titles, tags and event filtering

Status: Supported in source

Titles identify events while supported tags and filters help operators locate the right webinar in the account.

### What is this feature or requirement for?

Titles identify events while supported tags and filters help operators locate the right webinar in the account.

### How does it help?

A growing programme can distinguish campaigns, avoid editing the wrong event and find reusable examples faster.

### What happens if you do not have it?

Operators browse a less organised event list or maintain their own external index.

### Why should it matter to the buyer?

Organisation becomes important when many similar sessions exist. Event-management tags are separate from CRM contact tags and should not be treated as the same object.

## EW24 · Clone webinar configuration

Status: Supported in source

Cloning creates a new webinar from supported parts of an existing event's configuration.

### What is this feature or requirement for?

Cloning creates a new webinar from supported parts of an existing event's configuration.

### How does it help?

Operators can reuse a tested starting point for another campaign and reduce repeated setup work.

### What happens if you do not have it?

The team rebuilds the configuration manually and compares settings by hand.

### Why should it matter to the buyer?

Review what copies and what resets, especially links, dates, integrations, payment configuration and personal data. Cloning is not proof of isolated agency sub-accounts.
