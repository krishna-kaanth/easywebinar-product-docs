# Migration

Migration assistance helps move supported assets and workflows from another platform.

This page explains the requirement in the context of EasyWebinar and preserves the supplied inventory status. Read the evidence section before treating an explanation of buyer value as a promise of current product support.

## Planning checklist

List the assets and dependencies that must work: recordings, page copy, registration fields, access routes, email rules, payment destinations, CRM data and analytics. Identify what can be transferred and what must be rebuilt or reconnected.

Test the complete new workflow before retiring the old event or subscription. This is implementation guidance; vendor-assisted migration or onboarding availability remains subject to the source status and current service terms.

## S7 · Migration help from another platform

Status: Unconfirmed

Migration assistance helps move supported assets and workflows from another platform.

### What is this feature or requirement for?

Migration assistance helps move supported assets and workflows from another platform.

### How does it help?

A buyer can evaluate switching effort before cancelling its existing service.

### What happens if you do not have it?

It must transfer recordings, pages, contacts and automations through its own documented process.

### Why should it matter to the buyer?

It matters for switching risk; the vendor's migration service must be distinguished from a general planning checklist.

### Workflow evaluation

Request the current service description and confirm the channels, hours, eligibility and deliverables relevant to the intended launch. For help material, follow a real supported task and record missing steps.

Written product documentation does not establish staffed support, a response SLA, a migration service or a delivered video tutorial.
