# Security and data-handling requirements

Security documentation must describe the controls and agreements supported by actual evidence. Product availability, platform readiness statements and independent attestations are different facts.

The source identifies encrypted delivery and GDPR-aligned wording with a DPA. It does not confirm a completed SOC 2 Type II report, regional hosting, HIPAA suitability or ISO/PCI certification of the webinar platform. Procurement should request current, scoped evidence.
