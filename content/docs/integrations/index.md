# Integration directory

Integrations connect webinar activity with the systems a business already uses for CRM, email, payments, automation and reporting. The exact connection method matters more than the presence of a logo.

This directory distinguishes native, middleware-assisted, external checkout or link-based and unconfirmed connections. Each named-tool page explains the practical value and lists the technical details the team must verify. Salesforce Pardot is not the same integration as Sales Cloud.
