# Payment and checkout integrations

External checkout and commerce connections link supported tools such as SamCart, ThriveCart, Braintree, ClickBank or JVZoo to the webinar workflow.

This page explains the requirement in the context of EasyWebinar and preserves the supplied inventory status. Read the evidence section before treating an explanation of buyer value as a promise of current product support.

## U114 · SamCart / ThriveCart / Braintree / ClickBank / JVZoo

Status: Supported in source

External checkout and commerce connections link supported tools such as SamCart, ThriveCart, Braintree, ClickBank or JVZoo to the webinar workflow.

### What is this feature or requirement for?

External checkout and commerce connections link supported tools such as SamCart, ThriveCart, Braintree, ClickBank or JVZoo to the webinar workflow.

### How does it help?

A seller may retain an existing checkout or commerce process instead of rebuilding every offer.

### What happens if you do not have it?

The team must use another supported route or manually reconcile purchases and attendee records.

### Why should it matter to the buyer?

It matters for stack continuity; each named tool needs its own connection-mode and event-coverage evidence rather than a blanket native-integration claim.

### Workflow evaluation

Use an approved test purchase route and inspect the complete journey from the webinar offer to the payment result. Check what appears to the viewer, what the processor records and what transaction information returns to the webinar system.

Payment-provider availability does not prove support for instalments, coupons, taxes, refunds or every checkout layout. Distinguish event tickets from purchases made during a free session.
